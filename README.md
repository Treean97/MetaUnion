# MetaUnion

## 프로젝트 소개
Unity 엔진을 기반으로한 메타버스 게임입니다.

## 본 프로젝트의 목표
1. Photon을 이용한 멀티 환경 구축
2. CI/CD 파이프라인 구축
3. 로그인 시스템, 사용자 데이터 클라우드 저장 및 불러오기
